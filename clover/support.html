Technical Support

Help with Clover

Troubleshooting guidance for folder access, multi-pane browsing, file operations, previews, and purchases on macOS.

What Clover supports

Clover provides single-pane, dual-pane, and four-pane file browsing, list and grid views, Quick Look, drag and drop, search, sorting, filtering, and common file operations.

Common questions

A folder cannot be opened

Confirm that the folder still exists and is available on your Mac. Select it again when macOS asks for access, especially after the folder was moved, renamed, or restored from external storage.

A pane does not refresh

Refresh the active pane or switch to another folder and back. For external drives and cloud-managed folders, confirm that the volume is mounted and the content is available locally.

Copy, move, rename, or drag and drop fails

Check whether the item is locked, in use by another app, or located in a protected macOS folder. Make sure both source and destination folders remain accessible.

Quick Look does not appear

Preview availability depends on the selected file type and macOS Quick Look support. Some formats do not provide a system preview.

A purchase is not recognized

Confirm that the Mac App Store uses the Apple Account that made the purchase, then open the upgrade page and restore purchases.

Before requesting support

  • Install the latest Clover and macOS updates available to you.
  • Restart Clover and repeat the operation once.
  • Note whether the issue affects one folder, one drive, or every location.
  • Record the Clover version and the exact steps that reproduce the issue.

Contact support

Use the developer contact information on the Clover App Store listing. Include your macOS version, Clover version, reproduction steps, and whether the issue involves local storage, external drives, or protected folders.
