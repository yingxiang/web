Technical Support

Help with SplitWindow

Troubleshooting guidance for window discovery, permissions, layouts, multiple displays, previews, shortcuts, and purchases.

System requirement: macOS 14.0 or later.

Getting started

  1. Open New Layout from the SplitWindow menu, or use the configured layout shortcut.
  2. Choose a layout. SplitWindow uses only eligible windows on the display containing the mouse pointer.
  3. Drag windows between slots or replace them from the Other Windows strip.
  4. Adjust the layout dividers, then select Apply.

Common questions

SplitWindow cannot move or resize windows

Open System Settings > Privacy & Security > Accessibility and enable SplitWindow. If the app is missing, use the draggable SplitWindow icon shown by the app to add the current build. After replacing or reinstalling the app, remove an obsolete entry and add the current app again if necessary.

A window does not appear in the layout

Make sure the window is visible, not minimized, on the current macOS Space, and on the display containing the mouse pointer when you start the layout. Utility panels, full-screen windows, desktop elements, and windows that cannot be moved or resized are not eligible.

The layout opens on the wrong display

Move the mouse pointer onto the intended display before opening New Layout or pressing a layout shortcut. Each operation targets only that display.

Window previews are not visible

Previews require Screen Recording permission in System Settings > Privacy & Security > Screen Recording. This permission is optional; without it, SplitWindow shows the application's icon and name. Restart SplitWindow if macOS requests it after changing the permission.

A global shortcut does not work

Open Settings and confirm the shortcut assigned to the action. Choose a different key combination if it conflicts with macOS or another app. All layout shortcuts are configured independently.

A purchase is not recognized

Confirm that the Mac App Store is signed in with the Apple Account used for the purchase. Open SplitWindow Pro and use Restore Purchases. StoreKit requires an internet connection to load products and refresh entitlement status.

A Pro layout does not continue after purchase

This is expected. Opening the purchase page ends the current layout operation. After the purchase or restore completes, start a new layout and select the Pro layout again.

Before requesting support

  • Install the latest SplitWindow and macOS updates available to you.
  • Quit and reopen SplitWindow, then repeat the operation once.
  • Record your macOS version and SplitWindow version.
  • Include the layout selected, number of displays, and whether the issue occurs with one app or every app.
  • For permission issues, include a screenshot of the relevant Privacy & Security settings page with private information removed.

Contact support
