Technical Support

Help with ImageTrans

Guidance for image conversion, GIF frame extraction, background removal, clarity enhancement, editing, exports, and purchases.

System requirement: macOS 14.0 or later.

Getting started

  1. Open Quick Processing to add images or a folder for batch conversion, or open Icon Editor to edit one image.
  2. Choose the output format, compression, background, and size settings.
  3. Review the target dimensions, then start processing or export the edited image.

Common questions

Which formats are supported?

PNG, JPEG/JPG, and WebP can be converted and edited. GIF files are accepted in Quick Processing and are extracted into composited frames in display order; ImageTrans does not create animated GIF files.

Why does PNG not show a quality percentage?

PNG output uses lossless compression, so the four lossy quality percentages do not apply. Choose JPEG or WebP when you need adjustable lossy compression.

Why did JPEG change to PNG?

JPEG cannot store transparency. When background removal produces transparent pixels, ImageTrans switches JPEG output to PNG. WebP can also preserve transparency.

Clarity enhancement takes a long time

Enlargement above 1× uses a bundled local Core ML model and can require substantial memory and processing time, especially for large images. Keep ImageTrans open, try a smaller image or scale, or cancel and retry.

Background removal missed part of the subject

In Icon Editor, draw a selection around the subject to run recognition in that region, then use the erase brush to remove unwanted mask areas. Undo, redo, and reset are available.

Why can the free version export only at 0.5×?

The free version can preview editing features and process up to three batch inputs, but exported results are limited to 0.5×. Premium unlocks unlimited batches and export sizes from 0.5× through 4×.

A purchase is not recognized

Confirm that the Mac App Store is signed in with the Apple Account used for the purchase. Open the Premium page and choose Restore Purchases. An internet connection is required for Apple to load products and refresh entitlements.

Before requesting support

  • Install the latest ImageTrans and macOS updates available to you.
  • Quit and reopen ImageTrans, then repeat the operation once.
  • Record your macOS version, ImageTrans version 1.0.0, source format and dimensions, and selected output settings.
  • Include the exact error message. Do not send private source images unless necessary and safe to share.
